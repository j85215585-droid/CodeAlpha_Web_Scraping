# CodeAlpha_Web_Scraping
Web Scraping project using Python, Requests, BeautifulSoup, Pandas, and Matplotlib to extract and analyze book data from a website.
# Book Data Web Scraping

## Project Overview

This project demonstrates web scraping using Python, Requests, and BeautifulSoup. Data was collected from a public website containing book information and converted into a structured dataset for analysis.

## Technologies Used

* Python
* Requests
* BeautifulSoup
* Pandas
* Matplotlib
* Jupyter Notebook

## Data Extracted

* Book Title
* Book Price
* Book Rating

## Project Workflow

1. Download webpage content
2. Parse HTML using BeautifulSoup
3. Extract book information
4. Store data in a Pandas DataFrame
5. Export data to CSV
6. Create visualizations

## Visualizations

* Rating Distribution
* Rating Percentage Pie Chart
* Price Distribution
* Top 10 Most Expensive Books

## Key Findings

* Successfully extracted structured data from a website.
* Collected book titles, ratings, and prices.
* Created a reusable dataset for analysis.
* Demonstrated the complete web scraping pipeline.

## Conclusion

This project shows how web scraping can be used to collect online data and transform it into meaningful insights using Python-based data analysis tools.
